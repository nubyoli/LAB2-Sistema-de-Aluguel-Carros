# MomentCar — front-end

React + TypeScript + Vite, preservando as versões e a estrutura do projeto base.

```sh
npm ci
npm run dev
```

O front usa `/api`, encaminhado pelo Vite para `http://localhost:8080`. Inicie o back-end antes de usar login/cadastro. Não inclua senhas ou chaves do Supabase aqui.

- Build: `npm run build`.
- Preview do build: `npm run preview` (a API ainda precisa estar em execução).
- Instruções completas: [README principal](../README.md) e [guia Supabase](../docs/SUPABASE.md).
